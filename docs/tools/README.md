## 视频播放器

[Miteiru](https://github.com/hockyy/miteiru)：免费的桌面视频播放器（Windows / macOS / Linux），可以播放本地视频（字幕支持 srt / ass / vtt）和 YouTube 链接（读取视频自带的字幕）。日语字幕会自动分词并标注假名，点击单词即可离线查询 JMdict 和 KANJIDIC（释义为英文），并显示音调和活用形；支持双语字幕、单句重复和导出 Anki 卡片，也支持普通话、粤语和越南语。

## 打印与排版

[Large Print Maker](https://largeprintmaker.com/)：免费网页工具，把粘贴的任意文字排成 18/24/28 磅的大字号 PDF，在浏览器内生成、不上传内容、无需注册。适合老花或低视力学习者，以及要打印分发的场景（歌词、经文、单词表、练习纸）；日文版还带平假名并び替え练习、标注假名的歌谣与经文页面。
